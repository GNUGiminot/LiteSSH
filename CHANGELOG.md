# История изменений

## 1.1.7 — 2026-09-29

### Git

- Проверка ссылки на репозиторий кнопкой рядом с полем (и в «Проверить») — без выбора папки: найден ли репозиторий, пустой ли, есть ли доступ, какие ветки, будет ли создана ветка.
- Для несуществующего репозитория показывается понятная причина и кнопка «Создать репозиторий» (GitHub, GitLab, Bitbucket).
- Поддержаны не только GitHub, но и GitLab, Gitea, Bitbucket и собственные серверы (https и SSH); транспорт `ext::`, локальные пути и токены в ссылке отклоняются.
- Git запускается без интерактивных запросов логина — операции больше не «зависают» молча до таймаута.
- Публикация сначала проверяет удалённый репозиторий и не создаёт коммит/origin в папке, если он недоступен.
- Введённая ссылка больше не перетирается значением origin при проверке папки.

### Подключение и терминал

- Таймаут подключения не идёт, пока открыт диалог ключа хоста — соединение больше не обрывается, если отпечаток проверяют дольше 20 секунд.
- Баннер и первое приглашение сервера (и локального терминала) больше не теряются: вывод копится до монтирования терминала.
- В историю команд не попадает то, что вводится после запроса пароля (sudo, ssh, gpg…), и строки с ведущим пробелом.
- Вставка использует bracketed paste: многострочный текст не выполняется сразу и при синхронном вводе уходит во все панели.
- Смена типа ключа сервера (например, rsa → ed25519) показывается как предупреждение о смене ключа, а не как новый хост.
- Установка ключа на сервер работает через бастион (ProxyJump).
- Соединение, закрытое сервером без ошибки, завершает попытку сразу, а не по таймауту.
- Метрики не запускают новый замер, пока не пришёл предыдущий; у команд есть таймаут — каналы SSH больше не забиваются.
- Журнал сессии не рвёт многобайтные символы UTF-8.

### Туннели

- SOCKS5 (`-D`): данные, отправленные сразу после запроса, больше не теряются; «успех» отправляется только после открытия канала, при отказе клиент получает код ошибки.
- Туннель с ошибкой (например, занятый порт) перезапускается повторным запуском.
- Split view: при закрытии главной панели туннели, SFTP-очередь и MCP-мост переходят к оставшейся панели, а не отключаются.

### Файлы (SFTP)

- Если размер файла на сервере прочитать не удалось, скачивание завершается ошибкой, а не пустым файлом с отметкой «готово».
- При скачивании папки символические ссылки раскрываются (с защитой от циклов), битые пропускаются.

### MCP

- Запись через «битую» символическую ссылку внутри корня запрещена — она могла вести за пределы разрешённой области.
- Остановка моста больше не зависает на открытых соединениях клиента.
- Сервер сообщает клиентам актуальную версию приложения.

### Хранилище и сессии

- Включение и отключение мастер-пароля выполняется одной транзакцией; при сбое режим откатывается, секреты не становятся нерасшифровываемыми.
- Импорт `~/.ssh/config`: поддержаны `Include`, `ProxyJump`, форма `ключ=значение`, пути в кавычках; блоки `Match` больше не прилипают к предыдущему хосту; повторный импорт не создаёт дубли.
- Экспорт/импорт JSON сохраняет бастион, проброс агента и теги; повторный импорт не создаёт дубли.

### Оформление

- Активная вкладка читаема в светлой теме.
- Предупреждения и статусы в диалогах MCP и Git читаемы в светлой теме.
- Второстепенный текст стал контрастнее в обеих темах.
- Редактор кода, просмотрщик и редактор скриптов следуют теме приложения.
- Кнопка «Переподключить» больше не перекрывает панель поиска в терминале.
- Диалог Git использует общий слой окон — подтверждения не прячутся под ним.

### Обслуживание

- Добавлен интеграционный тест `npm run test:ssh`: локальный SSH-сервер под Electron проверяет ожидание ключа хоста, буфер вывода, SOCKS, перезапуск туннелей, split, бастион, импорт сессий.

## 1.1.6 — 2026-09-23

### Подключение

- Панель подключения увеличена и заменена горизонтальной шкалой из четырёх этапов.
- Для каждого этапа показывается отдельный тайминг, а справа — общее время подключения.
- Текущая операция и причина ошибки теперь отображаются в отдельной заметной строке состояния.

## 1.1.5 — 2026-09-23

### GitHub

- Добавлен мастер публикации локальной или серверной папки в существующий репозиторий GitHub.
- Добавлены выбор `.gitignore`, предварительный список изменений и предупреждение о возможных секретах.
- Синхронизация выполняется без force push и останавливается при расхождении историй.
- Для локального проекта поддержан вход через Git Credential Manager; сервер использует собственную Git-аутентификацию.

### MCP

- В интерфейсе пояснено различие между локальным MCP для Claude Code и удалённым HTTPS connector для Claude.

## 1.1.4 — 2026-09-23

### Передача файлов

- Последовательная FIFO-очередь для каждого SSH-сеанса и независимая работа разных сеансов.
- Отдельный SFTP-канал на задание, прогресс сканирования, файлов и байтов.
- Безопасная передача через `.litessh-part`, проверку размера и атомарную замену результата.
- Явное продолжение прерванной передачи и открытие расположения скачанного файла.

### MCP

- Независимые MCP-мосты для нескольких активных SSH-сессий.
- Конфигурации и отдельные токены для Codex, Claude Code и универсальных MCP-клиентов.
- Панель выполняющихся и завершённых операций, фильтры и экспорт metadata-only журнала.
- Автоматический отзыв доступа при закрытии связанной SSH-сессии.

### Обслуживание

- Документация приведена в соответствие с фактической архитектурой 1.1.4.
- Исправлен NUL-байт в исходнике главного процесса; временный каталог `.tmp` исключён из Git.
- Добавлена автоматическая Windows-сборка установщика с поддержкой подписи через секреты CI.

Практическая проверка больших передач и восстановления после обрыва выполняется владельцем проекта
на целевом сервере отдельно.
