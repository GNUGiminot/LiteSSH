# История изменений

## 1.1.5 — 2026-09-23

### GitHub

- Добавлен мастер публикации локальной или серверной папки в существующий репозиторий GitHub.
- Добавлены выбор `.gitignore`, предварительный список изменений и предупреждение о возможных секретах.
- Синхронизация выполняется без force push и останавливается при расхождении историй.
- Для локального проекта поддержан вход через Git Credential Manager; сервер использует собственную Git-аутентификацию.

### MCP

- В интерфейсе пояснено различие между локальным MCP для Claude Code и удалённым HTTPS connector для Claude.

## 1.1.4 — 2026-09-23

### Передача файлов

- Последовательная FIFO-очередь для каждого SSH-сеанса и независимая работа разных сеансов.
- Отдельный SFTP-канал на задание, прогресс сканирования, файлов и байтов.
- Безопасная передача через `.litessh-part`, проверку размера и атомарную замену результата.
- Явное продолжение прерванной передачи и открытие расположения скачанного файла.

### MCP

- Независимые MCP-мосты для нескольких активных SSH-сессий.
- Конфигурации и отдельные токены для Codex, Claude Code и универсальных MCP-клиентов.
- Панель выполняющихся и завершённых операций, фильтры и экспорт metadata-only журнала.
- Автоматический отзыв доступа при закрытии связанной SSH-сессии.

### Обслуживание

- Документация приведена в соответствие с фактической архитектурой 1.1.4.
- Исправлен NUL-байт в исходнике главного процесса; временный каталог `.tmp` исключён из Git.
- Добавлена автоматическая Windows-сборка установщика с поддержкой подписи через секреты CI.

Практическая проверка больших передач и восстановления после обрыва выполняется владельцем проекта
на целевом сервере отдельно.
