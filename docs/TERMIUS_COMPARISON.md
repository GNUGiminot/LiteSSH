# LiteSSH vs Termius — анализ возможностей

Termius — зрелый коммерческий кроссплатформенный SSH-клиент (Windows/macOS/Linux/iOS/Android)
с облачной синхронизацией и командными функциями. Ниже — что у Termius есть, а в LiteSSH пока нет,
сгруппировано по ценности для внедрения. Основано на публично известной функциональности Termius.

## Что уже есть в LiteSSH (паритет с Termius)

- Терминал с вкладками, темы, поиск, 256 цветов
- SFTP-менеджер файлов, передачи, предпросмотр/правка
- Менеджер SSH-ключей: генерация, импорт, деплой на сервер
- Проброс портов: local / remote / dynamic (SOCKS)
- ProxyJump / прыжок через бастион
- Сниппеты команд
- Импорт из ~/.ssh/config
- Локальный терминал
- Шифрование секретов (у нас — keychain ОС; у Termius — облако + мастер-пароль)

## Крупные пробелы (высокая ценность)

### 1. Облачная синхронизация и мультиустройство
Termius синхронизирует хосты, ключи, сниппеты, настройки между всеми устройствами (в т.ч. мобильными)
через сквозное шифрование. **У LiteSSH всё локально.** Это флагманская фича Termius и главное отличие.
→ Реализация нетривиальна (нужен бэкенд/E2E-крипто); для «клиента для себя» частично закрывается
экспортом/импортом JSON, который уже есть.

### 2. Мобильные приложения (iOS/Android)
Termius — полноценный клиент на телефоне/планшете. LiteSSH — только десктоп (Electron).
→ Вне текущего скоупа; архитектура ssh-core в main-процессе теоретически переносима.

### 3. SSH-агент и переброс агента (agent forwarding) — ✅ РЕАЛИЗОВАНО
Termius умеет пробрасывать ключи агента на удалённый хост (`ForwardAgent`), чтобы прыгать дальше без
копирования приватных ключей. Добавлено в LiteSSH: чекбокс «Проброс SSH-агента» в форме сессии
(`agentForward: true` в ssh2 + запрос проброса в shell-канале).

### 4. Синхронизированный ввод в несколько сессий
Termius (и MobaXterm) умеют слать одну команду сразу в несколько открытых сессий одновременно.
У нас нет (и split view терминала тоже пока нет).
→ Средняя сложность; частично зависит от split view.

## Средние пробелы

### 5. Host-мониторинг / метрики — ✅ РЕАЛИЗОВАНО
Termius показывает CPU/RAM/диск/сеть удалённого хоста на дашборде. Добавлено: кнопка «Метрики»
(иконка пульса) для активной SSH-вкладки открывает дашборд с CPU% (два замера /proc/stat),
память, диск /, load average и аптайм; опрос раз в 2.5 с по exec-каналу существующего соединения.

### 6. SFTP: докачка, вкладки передач, фоновая очередь между сессиями — ✅ ЧАСТИЧНО
У Termius более развитый файловый воркфлоу. Добавлена **докачка (resume)**: прерванную передачу
(отмена/обрыв/ошибка) можно продолжить с места остановки — движок передач переписан на потоковый
с учётом смещения приёмника; в очереди появилась кнопка «Возобновить». Глобального менеджера
передач между сессиями по-прежнему нет.

### 7. Автозаполнение команд / история с автодополнением — ✅ ЧАСТИЧНО
Termius предлагает автодополнение по истории и известным командам. Добавлено: история команд
захватывается автоматически и ищется в палитре команд (Ctrl+Shift+P) вместе со сниппетами;
любую команду из истории можно сохранить как сниппет. Инлайн-автодополнения в самом терминале нет.

### 8. Теги и мощный поиск по хостам — ✅ РЕАЛИЗОВАНО
Termius: теги, группы, быстрый фильтр по большому парку хостов. Добавлено: поле тегов в форме
сессии, строка поиска в сайдбаре (по имени/хосту/пользователю/папке/тегам), кликабельные
теги-фильтры и чипы тегов в карточках сессий.

### 9. Known hosts UI / управление отпечатками — ✅ РЕАЛИЗОВАНО
У нас проверка host key есть (TOFU + алерт). Добавлен экран управления сохранёнными отпечатками
(иконка щита в шапке): просмотр host:port/тип/отпечаток и удаление записи для сброса доверия.

## Мелкие пробелы / полировка

- **Telnet, Mosh, последовательный порт (serial)** — Termius поддерживает; у нас только SSH.
- **Autocomplete/подсветка в самом терминале** (fig-подобное) — нет.
- **Темизация интерфейса по темам** — у нас 4 схемы терминала + акцент; Termius богаче.
- **Командная работа/шаринг хостов в команде (Teams)** — корпоративная фича, вне скоупа личного клиента.
- **SSO / SAML вход, аудит-лог команды** — корпоратив, вне скоупа.
- **Синхронизация сниппетов между устройствами** — часть облака.
