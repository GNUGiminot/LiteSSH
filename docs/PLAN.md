# План разработки LiteSSH

Этапы пересобраны так, чтобы каждый заканчивался работающим инструментом, которым уже можно пользоваться ежедневно (dogfooding с первой же фазы).

> **Статус (v1.0.1): фичи заморожены.** Ядро реализовано и превосходит референсы (WindTerm/MobaXterm/
> SecureCRT) там, где это осмысленно. Оставшиеся идеи (cd↔SFTP-синхронизация, --help-автокомплит,
> встроенные скрипты) — scope-creep с низким ROI; см. [FINAL_AUDIT.md](FINAL_AUDIT.md). Дальше — только
> стабилизация, полировка и CI, без новых модулей.

Дополнительно к фазам реализовано: настраиваемые горячие клавиши (меню настроек, перепривязка/сброс) и
mc-стиль панель F-клавиш в файловом менеджере (F3 просмотр, F4 правка, F5 копирование, F7 папка, F8 удаление).

Цель: заменяет PuTTY.

- [x] ConnectionManager на ssh2: пароль / ключ-файл / ssh-agent
- [x] **Host key verification (TOFU + алерт при смене)**
- [x] Терминал: xterm.js + fit/webgl/search/web-links, вкладки, Ctrl+Shift+C/V, 256 цветов, батчинг IPC
- [x] Сохранённые сессии: CRUD, папки-группы, дабл-клик → подключение
- [x] Quick connect: `user@host:port` (агент → fallback на пароль)
- [x] Пароли в keychain ОС (safeStorage)
- [x] Keep-alive, статус подключения в табах и статус-баре
- [ ] Автореконнект при обрыве (сейчас — пометка «отключено», переподключение вручную)

**Готово, когда:** ежедневно подключаюсь ко всем своим хостам только через LiteSSH.

## Фаза 4 — v2.0: сетевой инструментарий (3–4 недели) — ⏳ частично сделано

- [x] Туннели: local (-L) / remote (-R) / dynamic SOCKS5 (-D), редактор, автостарт с сессией,
      мониторинг трафика (соединения/байты) в реальном времени; SOCKS5-хендшейк реализован вручную
- [x] **ProxyJump / бастион**: сессия может подключаться через другую сессию (forwardOut на цель)
- [x] Локальные терминалы (node-pty): выбор шелла (PowerShell 7/Windows PowerShell/cmd/WSL/Git Bash),
      вкладки; при отсутствии нативного модуля — мягкая деградация без падения приложения
- [x] Логирование сессий в файл: кнопка в шапке, вывод пишется без ANSI-кодов, дозапись (append)
- [x] Проброс SSH-агента (ForwardAgent) — чекбокс в форме сессии
- [x] Управление known_hosts в UI (просмотр/удаление отпечатков) — из Termius-анализа
- [x] Сворачивание в трей: закрытие окна прячет в трей, выход — только из меню трея
- [x] Цепочки из нескольких бастионов (рекурсивный ProxyJump, защита от циклов) — проверено 2-hop тестом
- [x] Профили-шаблоны сессий: «скопировать настройки из» существующей сессии при создании новой
- [~] Макросы: запись/воспроизведение — покрыто многострочными сниппетами (сниппет с \n выполняется целиком)

## Отложено (после v2.0, по потребности)

PDF-предпросмотр, просмотр архивов, drag-out удалённых файлов в ОС, Mosh/Serial, порт ssh-core на Tauri, если захочется настоящего «lite».

## Метрики (проверяются на каждой фазе)

| Метрика | Цель |
|---|---|
| Холодный старт | < 3 с |
| RAM без сессий | < 350 MB |
| Листинг 10 000 файлов | < 2 с, скролл 60 fps |
| Латентность терминала | на уровне PuTTY |
| Секреты на диске | только шифрованные, всегда |

## Риски

- **better-sqlite3 / node-pty — нативные модули**: пересборка под Electron ABI (electron-rebuild), проверять на всех трёх ОС в CI.
- **Производительность xterm при потоках вывода**: батчинг IPC обязателен с Фазы 1.
- **DnD между ОС и renderer** ограничен Electron API — drag-in надёжен, drag-out делаем позже осознанно.
- **Скоуп-крип**: MobaXterm велик соблазн копировать целиком; правило — фича входит в фазу только если ей будет пользоваться владелец.
